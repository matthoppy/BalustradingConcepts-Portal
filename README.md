# Balustrading Concepts Portal

CRM and customer portal for Balustrading Concepts (Auckland), to be served at
`portal.balustrading.co.nz`.

It covers the full job flow: website enquiry → site survey → per-metre quote → online acceptance and
50% deposit → Unex order → install → final invoice, with Xero for accounts.
